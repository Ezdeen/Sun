# نموذج التهديدات والضوابط (SECURITY)

## موجرات التهديدات (STRIDE مختصراً) والضوابط المضادة

| التهديد | السيناريو | الضوابط (مُنفَّذة ومُختبرة) |
|---|---|---|
| **تجاوز المصادقة** | «دخول تجريبي» بأي بريد (عيوب النظام القديم #7) | لا يوجد أي مسار تجريبي في API. الحسابات التجريبية بذر تطوير فقط (`seed:demo` يرفض الإقلاع خارج development). مختبر E2E. |
| **تخمين كلمات المرور** | هجوم قاموسي على /auth/login | argon2id (m=65536, t=3, p=2) + قفل 5 محاولات/15 دقيقة + حد سرعة 30/دقيقة على المسار + أحداث تدقيق + تحقق دمية عند مستخدم غير موجود (توقيت موحد). |
| **سرقة الرموز** | XSS يقرأ localStorage | **لا tokens في URL أو localStorage/sessionStorage إطلاقاً.** Access في ذاكرة الصفحة فقط؛ Refresh في كوكي HttpOnly; Secure (إنتاج) SameSite=Lax scoped على `/api/v1/auth`. |
| **إعادة استخدام Refresh** | تسريب كوكي واستخدامه مرتين | رموز أحادية الاستخدام مع تدوير؛ أي إعادة استخدام → إبطال **كل** جلسات المستخدم + حدث `refresh_reuse_detected`. مختبر E2E. |
| **تصعيد الصلاحيات** | دور يستدعي مساراً غير مسموح | RBAC صريح بالصلاحيات (`requirePermission`) على كل مسار محمي؛ مصفوفة الأدوار بيانات مطابقة بين الكود وJSON البذور باختبار آلي. مختبر (دور صحيح 200 / خاطئ 403 / بلا رمز 401). |
| **IDOR** | مواطن يقرأ طلب غيره | سياسة ظهور (VisibilityPolicy) في طبقة application لكل قراءة وانتقال؛ الرفض **404** (لا يكشف الوجود). مختبر E2E. |
| **تلاعب بالمال** | فوترة مزدوجة/توزيع ناقص | معاملة ذرّية واحدة + قفل صف الصفقة + **فهرس فريد جزئي في القاعدة** (فاتورة فعّالة واحدة/صفقة) + Idempotency-Key + حفظ المال خاصية مبرهنة باختبارات 500 حالة عشوائية + قيد ما بعد الكتابة. مختبر E2E. |
| **عبث بسجل التدقيق** | تعديل/حذف أحداث السلسلة | الجدولان append-only عبر **triggers في القاعدة** (تُرفض UPDATE/DELETE على مستوى الصف) + تحقق SHA-256 كامل (CLI + API للمدير) يكشف أول حدث مكسور. مختبر E2E (محاولة عبث فعليّة مرفوضة). |
| **كشف هويات** | تخزين رقم الهوية صريحاً | HMAC-SHA256 بفليبر سري (kid للتدوير) + آخر 4 خانات فقط. لا PII في السجلات (تعطيل authorization/cookie في pino redact). |
| **كسر مفاتيح التوقيع** | JWT بسر ضعيف/افتراضي | fail-fast: الإقلاع يفشل إنتاجياً بدون سر ≥32 بايت أو مع قيمة ضعيفة معروفة. مختبر في CI (Docker بدون أسرار يجب أن يفشل). |
| **CORS مفتوح** | `*` مع credentials (عيب قديم #10) | لا CORS أصلاً عند الخدمة من نفس الأصل (الوضع الإنتاجي)؛ عند التحديد تُقبل أصول صريحة فقط، والـ wildcard مرفوض إنتاجياً (fail-fast). |
| **حقن SQL** | مدخلات خبيثة | Drizzle معلْمَت بالكامل + TypeBox validation على كل مدخل. لا سلاسل SQL مدمجة من مدخلات. |
| **XSS / ترويج محتوى** | حقن سكربت في SPA | CSP صارم (self فقط) + helmet (HSTS إنتاجياً، no-sniff، frame-deny) + React escaping. |
| **DoW/الإغراق** | إغراق نقاط عامة | rate-limit عام 300/دقيقة + 20/دقيقة للتتبع العام + 30/دقيقة للتقدير + body limit 1MB. |
| **كشف أخطاء داخلية** | stack traces/SQL للعميل | Problem Details (RFC 7807) برموز ثابتة ورسائل عربية؛ التفاصيل في سجلات الخادم فقط. |

## أسرار النشر

| المتغير | التوليد | ملاحظات |
|---|---|---|
| `JWT_SECRET_KEY` | `openssl rand -base64 48` | يدعم التدوير عبر `JWT_KEY_ID` (kid في رأس الرمز) |
| `IDENTITY_PEPPER` | `openssl rand -base64 48` | تدويره يتطلب إعادة هاشدة للهويات — راجع RUNBOOK |
| `DATABASE_URL` | Supabase (pooler 6543) | اتصال خدمة ذو صلاحية يتجاوز RLS |

**لا توجد أي قيمة افتراضية قابلة للاستخدام لأي سر في الكود.**

## حدود النطاق (Out of scope)
لا إشعارات SMS/Email فعلية؛ لا دفع فعلي للمستحقات؛ AnchorPort تصميم فقط (NoOp — **لا مراجع بلوك تشين وهمية**).
