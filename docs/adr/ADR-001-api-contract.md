# ADR-001 — عقد API ملتزم به في المستودع

**الحالة:** مقبول (2026-09)

## السياق
النظام القديم كان بلا عقد معلن، فتراكمت مسارات غير مستخدمة و16 راوتر CRUD مولّداً. الواجهة كانت تخمّن أشكال الاستجابات.

## القرار
- `openapi.json` ملف مُلتزم به في جذر المستودع (45 مساراً)، يُولَّد بالأمر `pnpm --filter @waste/backend export-openapi` من مخططات TypeBox نفسها التي تتحقق في المدخلات (مصدر واحد للحقيقتين).
- عميل الواجهة **مولّد من العقد**: `openapi-typescript` يولّد الأنواع، `openapi-fetch` ينفّذ الاستدعاءات بأنواعها.
- بوابة CI (contract freshness) ترفض الاندماج إذا تغيرت الشيفرة دون تحديث العقد.

## العواقب
- ✅ مستحيل عملياً إضافة مسار غير موثق (CI + عملية التوليد).
- ✅ تغيير كسر العقد يظهر كـ diff في ملف نصي قابل للمراجعة.
- ⚠️ خطوة توليد إضافية عند كل تغيير API (موثقة في AGENTS.md الوصفة 5).
